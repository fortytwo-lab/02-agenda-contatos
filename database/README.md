# 🗄️ Banco de Dados

Esta pasta reúne os artefatos relacionados ao planejamento,
modelagem e implementação do banco de dados da Agenda de Contatos.

## Estrutura

- `DER/` — Diagramas Entidade-Relacionamento.
- `DL/` — Diagramas Lógicos do banco de dados.
- `scripts/` — scripts SQL utilizados para criação e manutenção do banco.

## Tecnologia

O projeto utilizará **MySQL** na etapa de persistência em banco de dados.

> Os artefatos desta pasta serão adicionados e refinados conforme
> a evolução do projeto.
