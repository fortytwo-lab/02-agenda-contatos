# 📒 Agenda de Contatos

Sistema para gerenciamento de contatos desenvolvido pela **FortyTwo Lab**
como parte do Projeto Final da disciplina de Programação Orientada a Objetos.

O projeto será desenvolvido **progressivamente**, permitindo acompanhar a
evolução da aplicação e a introdução dos conceitos de Java, Programação
Orientada a Objetos, interface gráfica e persistência de dados.

---

## 🎯 Objetivo

Desenvolver uma aplicação para gerenciamento de contatos que permita
cadastrar, consultar, editar e excluir informações de pessoas.

Além do produto final, o projeto tem como objetivo registrar o processo de
desenvolvimento do software, incluindo planejamento, documentação,
versionamento e evolução do código.

---

## ⚙️ Funcionalidades Planejadas

A aplicação deverá permitir:

- ➕ Cadastrar contatos;
- 📋 Listar contatos;
- 🔎 Buscar contatos;
- ✏️ Editar contatos;
- 🗑️ Excluir contatos;
- 💾 Persistir os dados;
- 🖥️ Interagir com o sistema por meio de interface gráfica.

As funcionalidades serão implementadas progressivamente durante o
desenvolvimento do projeto.

---

## 👤 Dados do Contato

Inicialmente, cada contato poderá possuir informações como:

- Nome;
- Endereço;
- Celular;
- E-mail;
- Sexo.

Os atributos poderão ser alterados ou ampliados conforme a evolução
do projeto.

## 🗄️ Banco de Dados

O projeto utilizará **MySQL** para persistência dos dados em uma etapa
posterior do desenvolvimento.

Os artefatos relacionados ao banco de dados serão armazenados em:

```text
database/
├── DER/
├── DL/
└── scripts/
```

Essa pasta permitirá registrar desde a modelagem até os scripts utilizados
para criação e manutenção do banco.

## 🌿 Fluxo de Desenvolvimento

O desenvolvimento será realizado utilizando branches específicas para
novas funcionalidades, correções e melhorias.

Fluxo utilizado pela equipe:

`Branch` → `Desenvolvimento` → `Commit` → `Push` → `Pull Request` → `Review` → `Merge`

A branch `main` deverá manter versões integradas e estáveis do projeto.

---

## 🏷️ Versionamento

A evolução da Agenda de Contatos será registrada por meio de commits,
branches e tags.

Cada versão representará uma etapa importante da evolução do projeto,
permitindo acompanhar as mudanças realizadas desde as primeiras
implementações até a aplicação final.
