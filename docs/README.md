# 📚 Documentação

Esta pasta reúne a documentação produzida pela equipe durante o
planejamento, desenvolvimento e apresentação da Agenda de Contatos.

## Estrutura

- `uml/` — diagramas UML.
- `ui-ux/` — planejamento das interfaces.
  - `wireframes/`
  - `mockups/`
  - `prototypes/`
- `diagrams/` — fluxogramas e outros diagramas.
- `presentations/` — apresentações do projeto.

> A documentação poderá ser atualizada durante o desenvolvimento,
> registrando a evolução das decisões tomadas pela equipe.
