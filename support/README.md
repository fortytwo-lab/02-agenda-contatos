# 🧰 Materiais de Apoio

Esta pasta reúne materiais externos e auxiliares utilizados durante
o desenvolvimento da Agenda de Contatos.

## Estrutura

- `documents/` — documentos, artigos, apostilas e manuais.
- `videos/` — referências para vídeos e videoaulas.
- `tutorials/` — tutoriais utilizados pela equipe.
- `references/` — links e referências técnicas.

> Os materiais desta pasta servem como apoio ao desenvolvimento
> e não constituem documentação produzida pela equipe.
